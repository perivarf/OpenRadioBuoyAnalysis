# OpenRadioBuoyAnalysis

Data and analysis code for the master's thesis *Integration of IMU Wave
Measurements into Open Radio Buoy Platform* (part of the Digital Twin of the
Oslo Fjord project), Department of Informatics, University of Oslo.

Analysis of wave measurements from the ORB (Open Radio Buoy) drifter: the raw
logs from the buoy, and the Python tools that turn them into wave spectra, wave
parameters (Hs, Tp, Tz, Tc), maps and the figures used in the thesis.

The repository holds **raw data and scripts only**. Everything the tools produce
(figures, `*_python.csv`, reconstruction work directories, per-config output) is
in `.gitignore` and is regenerated by running the scripts.

## Layout

```
tools/                                 the analysis code - see tools/README.md
20260731 Skjærhalden/                  set SKJAERHALDEN: 3 locations x 2 buoys (240/480 Hz)
20260830 Skjærhalden/                  set KATTEN: one 30 min drift off Katten, 480 Hz raw log
20261027 Timing Madgwick Kalman SDFix/ six sessions timing the on-board filters
power_measurement/                     power consumption logs (GPP-4323 + Keithley readings)
```

Each measurement directory holds one folder per logging session, named after the
session's start time `<stamp>` (`YYYYMMDD_HHMMSS`), and a `plot.sh` (and
`test_config.sh`) that runs the figure chain for that measurement.

### Files in a session folder (written by the buoy)

| File | Contents |
|---|---|
| `<stamp>_raw.bin` | The undecimated IMU stream (accel, gyro, on-chip SFLP) plus GPS records; format in `tools/conversion/rawlog.py` |
| `<stamp>_imu.csv` | The decimated IMU rows with on-board orientation (older firmware, without a raw log) |
| `<stamp>_gps.csv` | GPS fixes: position, velocity, accuracy |
| `<stamp>_ses.csv` | Session summary (start/stop, counts) |
| `<stamp>_cfg.csv` | The firmware configuration the session ran with (rates, filter, FIR taps, ...) |
| `<stamp>_ana.csv`, `<stamp>_spec.csv` | The buoy's own wave analysis and spectrum |
| `<stamp>_timing.csv` | On-board filter timing (the 20261027 sessions) |
| `<stamp>_notat.txt` | A hand-written note: the heading used in the figures |

## Quick start

Python 3 with `numpy`, `pandas`, `matplotlib`, `Pillow` (and optionally `scipy`
and the `ahrs_fusion` module for the NXP filter). From the repository root:

```bash
"20260830 Skjærhalden/plot.sh"                      # the whole figure chain for one set
python3 tools/script_plot.py SKJAERHALDEN            # maps + wave parameters for a set
python3 tools/script_postprocess.py "20260731 Skjærhalden/20260731_110303"
python3 tools/script_filter_timing.py "20261027 Timing Madgwick Kalman SDFix"
python3 tools/script_lora_range.py                   # LoRa range map
python3 tools/script_power_baseline_k.py           # power figure + component table
```

`power_measurement/` holds the logs from the power bench: `*_raw.csv` (time,
voltage, current, power from the GPP-4323), `*_sum.csv` (the logger's summary),
`keithley_readings.csv` (multimeter readings) and `legend_names.csv`.

See [tools/README.md](tools/README.md) for every script, the processing
pipeline and the output files.
